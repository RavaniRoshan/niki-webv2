Automatic test execution before any Git commit.

Unlike raw LLM assistants that hallucinate syntax and leave broken branches, Niki runs your actual test runner: cargo test, vitest, pytest, or go test.

Only when 100% of test assertions pass does Niki stage files and create a clean commit.
