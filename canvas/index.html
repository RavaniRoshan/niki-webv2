STAGE 01

Planner Stage

The Planner agent parses ASTs, inspects types and call graphs, and defines the exact files and test assertions needed.

STAGE 02

Hermetic Coder

The Coder executes strictly inside an isolated Docker container with zero access to your host machine or network.

STAGE 03

Test Runner

The Test Runner agent executes real test suites (cargo test, vitest, pytest). If any test fails, changes are reverted automatically.

STAGE 04

Reviewer & Git Output

The Reviewer performs AST security checks and commits only verified code to a clean Git branch for human pull request review.

Control your pipeline via MCP.

Expose your multi-agent pipelines to Claude Desktop, Cursor, or your external LLM framework using standard Model Context Protocol tools.

pipeline_list Find the pipeline.

Spawns ephemeral container, executes agent code, runs tests, and streams logs.
