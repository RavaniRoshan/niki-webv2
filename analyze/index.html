How the benchmark works

STEP 01

Hermetic Build Inspection

Niki reads your package manifests and lockfiles to determine if all dependencies can be resolved without requiring internet access during compilation.

STEP 02

Execution Sandbox Profiling

The engine spins up a temporary cgroup-constrained Docker container, runs your full test suite, and measures CPU memory limits and flake rates.
