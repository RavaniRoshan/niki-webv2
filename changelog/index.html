No. 0024 v1.7.0 Released October 7, 2026
Type: Security

Hermetic Network Egress Enforcement (`--hermetic`)

Coding agents should never have arbitrary internet access while compiling or modifying source files. The new `--hermetic` flag isolates the Docker sandbox network namespace completely.

Dependency caches are mounted read-only, preventing unexpected external calls, socket leaks, or package tampering during code generation.

Linux iptables filtering blocks all outbound connections outside the pre-authenticated model API socket.

“--hermetic flag” “zero egress leaks” “read-only cache mounts”
Verified isolated sandbox execution. 🔒
No. 0023 v1.6.4 Released October 2, 2026
Type: Architecture

Multi-Agent Parallel Sandbox Orchestration

Niki now spins up isolated sub-sandboxes for parallel test matrix execution. The Coder agent writes code in Container A while the Test Runner validates linting and unit tests across Containers B and C simultaneously.

Reduces total task cycle time by 48% on multi-package monorepos.
