Answers

Can I use the open-source CLI without a paid account? +
Yes, 100%. Niki's core CLI engine is completely open source under Apache-2.0 / MIT. You can run unlimited local Docker containers on your machine forever.
How does billing work for Team seats? +
Team seats are billed per active developer who triggers cloud sandboxes or shares workflow canvases. Viewer-only stakeholders have free access.
What happens if an agent produces failing tests? +
Niki will NEVER commit or create a Git branch if unit tests or AST linters fail. The agent rolls back the container layer and reports the failure logs.
