Privacy Policy

LAST UPDATED: OCTOBER 11, 2026

1. Zero Retention of Private Source Code

Your source code and repository data never leave your control. When using the local Niki CLI, all container builds, code generation, and test executions occur entirely within your local Docker daemon. Disposable containers are automatically pruned upon task completion.

2. Cloud Sandbox Isolation

For users on Niki Cloud Sandbox tiers, execution environments run in hermetically sealed virtual instances with ephemeral file systems. Containers are destroyed immediately upon branch creation. Your code is never used to train public machine learning or foundation models.

3. Network Egress Protection

By default, Niki enforces `--hermetic` networking on agent sandboxes during code modification and test execution. External network egress can be explicitly disabled to prevent data leakage.

4. Account and Billing Information

We collect essential account details (email, team name, authentication tokens) and process payments through PCI-compliant providers (Stripe). We do not store sensitive payment card details on our servers.

5. Telemetry & Opt-Out

The open-source Niki CLI does not send diagnostic telemetry by default. You can inspect all outbound traffic via source code on GitHub at RavaniRoshan/niki.

6. Contact Us

For questions or privacy inquiries, open an issue on GitHub or reach out to security@niki.dev.
