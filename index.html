Answers

Who is Niki for? +
Niki is built for developers, platform engineers, and software engineering teams who want the productivity of autonomous coding agents without the danger of unconstrained shell execution or broken repositories.
What does "hermetic multi-agent coding" mean? +
It means agents are strictly contained inside isolated Docker sandboxes. The Planner, Coder, Tester, and Reviewer run in a reproducible container environment with zero host access, compile and test their code, and only produce a clean Git branch.
How are Docker sandboxes isolated? +
Every sandbox operates with cgroup v2 resource limits, read-only root filesystems where appropriate, disabled network egress to prevent data leaks, and non-root user execution.
Why does Niki only output reviewable Git branches? +
Direct modifications to live developer files often cause subtle breaking changes. By packaging completed tasks into clean Git branches with verifiable test logs, developers maintain complete control over code review.
Can I use Niki with Claude, Cursor, and custom LLMs? +
Yes. Niki includes an MCP server implementation. You can point Claude Desktop, Cursor, or your internal LLM agents directly to Niki to run tasks in isolated containers.
Is Niki open source? +
Yes, the core Rust CLI and local Docker container engine are free and open source on GitHub at github.com/RavaniRoshan/niki.
